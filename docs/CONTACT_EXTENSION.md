# Contact — RAG Moderation Assistant

**Last updated:** November 4, 2026  
**Operator:** airesearchdog (“we,” “us”)

Use the addresses below for **questions about the extension, this website, or our policies**. We read mail sent to each address.

**Do not** email neighbor post or comment text to these addresses expecting an automated moderation report. Use the **extension side panel** instead (see [How to moderate user posts](https://www.airesearchdog.net/extension/how-to-moderate-user-posts)).

---

## info@airesearchdog.net {#info}

**General information** about RAG Moderation Assistant and airesearchdog.

**Examples — good fits for info@**

- What the extension does and who it is for  
- How the free moderation allowance or shared AI capacity works (high level)  
- Press, partnership, or “how do I cite / link to your tool?” questions  
- Feedback that is **not** a support ticket (suggestions, general comments about the project)

**[info@airesearchdog.net](mailto:info@airesearchdog.net)**

---

## help@airesearchdog.net {#help}

**Help using the extension** — install, settings, and day-to-day troubleshooting.

**Examples — good fits for help@**

- Chrome Web Store install, pinning the toolbar icon, or side panel will not open  
- Feed location, environment profile (Production vs Local dev), or API connection errors  
- **Email report** or **Open full report** not working as expected  
- Optional **Gemini API key (BYOK)** — where to paste the key, validation errors, or switching key on/off (see also the [Gemini key guide](https://www.airesearchdog.net/extension/get-gemini-api-key))

**[help@airesearchdog.net](mailto:help@airesearchdog.net)**

---

## admin@airesearchdog.net {#admin}

**Privacy, terms, legal, and data** questions about the extension and these published policies.

**Examples — good fits for admin@**

- Questions about the [Privacy policy](https://www.airesearchdog.net/extension/privacy) or [Terms of use](https://www.airesearchdog.net/extension/terms)  
- How moderation content, report email, or BYOK keys are handled  
- Requests related to data you submitted through the extension (access, correction, deletion — we will respond as our configuration and law allow)  
- Chrome Web Store listing or compliance questions directed at the operator

**[admin@airesearchdog.net](mailto:admin@airesearchdog.net)**
