# RAG Moderation Assistant — documentation

This page is the **top-level home** for all public **RAG Moderation Assistant** guides on airesearchdog.net. Use it as the entry point for moderators, testers, and policy readers. The guides below are listed in **recommended order** — the sequence most people follow from first install through daily moderation, optional setup, and legal pages.

## All guides (in order) {#guides}

1. **[Install RAG Moderation Assistant in Chrome](https://www.airesearchdog.net/extension/install-chrome-extension)** — Chrome Web Store install, pin the toolbar icon, and open the side panel.

2. **[Install (developer / unpacked)](https://www.airesearchdog.net/extension/install-chrome-extension-developer)** — Sideload from a release ZIP, Developer mode, enable on the extension card, and pin the icon.

3. **[Get the latest extension](https://www.airesearchdog.net/extension/get-latest-extension)** — Download the current sideload ZIP (build info and checksums).

4. **[How to moderate user posts](https://www.airesearchdog.net/extension/how-to-moderate-user-posts)** — Feed location, capture text, **Moderate**, read decisions, and copy notes.

5. **[Visual moderation step by step](https://www.airesearchdog.net/extension/visual-moderation-step-by-step)** — Screenshot walkthrough of the same workflow.

6. **[How to test the extension](https://www.airesearchdog.net/extension/how-to-test-extension)** — QA checklist for sideload and production builds.

7. **[Get a Gemini API key for moderation](https://www.airesearchdog.net/extension/get-gemini-api-key)** — Optional BYOK: Google AI Studio key saved in Options.

8. **[Important — AI-generated analysis](https://www.airesearchdog.net/extension/important-ai-generated-analysis)** — Read before acting on moderation suggestions.

9. **[Contact](https://www.airesearchdog.net/extension/contact)** — Email addresses (info, help, admin) and what each is for.

10. **[Privacy policy](https://www.airesearchdog.net/extension/privacy)** — Data the extension sends and how BYOK works.

11. **[Terms of use](https://www.airesearchdog.net/extension/terms)** — Rules for using the extension and site.
