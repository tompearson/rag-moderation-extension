Options

API calls go to Community Moderation Tool Universal (/api/moderate with the RAG provider). Secrets stay on the server.

Environment

Saves when you change the profile. Custom origin saves on blur or when you leave the field.

Moderation request

Default 45. Saved when you change this field. The side panel stops waiting at this limit; use Stop to cancel sooner.

Saved full report

Optional. Used when you click Email report in the side panel (sent in the API request). If mail still lands elsewhere, the production server may override delivery via RESEND_REPORT_TO.

Checkboxes save when changed. Report email saves when you leave the field or close Options. Buttons appear only when the API returns a saved report (moderationHistoryId). Full reports use the Card layout (same as Universal with saved card / email layout).

Platform intelligence

Same as Universal’s first two providers. Saves when you change the selection.

Moderation identity (dev)

Saves when you leave each field or close Options.

Feed location

Open the list, then scroll (wheel or trackpad) or use arrow keys and Enter to pick a state.

Feed location saves when you pick a state. Save all settings flushes any field still being edited.

Reset extension

Clears saved settings, sets profile to Production, and revokes granted API host permissions. Side panel draft text is not cleared.
