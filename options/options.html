Options

API calls go to Community Moderation Tool Universal (/api/moderate with the RAG provider). Secrets stay on the server.

Environment

Saves when you change the profile. Custom origin saves on blur or when you leave the field.

This build uses the Production profile.

Moderation request

Default 45. Saved when you change this field. The side panel stops waiting at this limit; use Stop to cancel sooner.

Saved full report

Optional. Used when you click Email report in the side panel (sent in the API request). If mail still lands elsewhere, the production server may override delivery via RESEND_REPORT_TO.

Checkboxes save when changed. Report email saves when you leave the field or close Options. Review this Decision, email, and open report appear only when the API returns a saved report (moderationHistoryId) — the same whether you typed the text or used Click on Text to Moderate on a page. Full reports use the Card layout (same as Universal with saved card / email layout).

Platform intelligence

Same as Universal’s first two providers. Saves when you change the selection.

RAG uses the server’s Gemini key on Render. Your personal key applies only to no RAG (phase 2 will add RAG BYOK).

Your Gemini API key (optional)

Stored only in this browser (chrome.storage.local). Used for no RAG moderations when enabled — sent to Universal over HTTPS per request, not saved on the server. Get a key from Google AI Studio. Test & save checks your key directly with Google. Moderation uses the profile from Environment above (Production in store builds).

A key is saved. Paste a new key to replace it, or use Remove.

Moderation identity (dev)

Saves when you leave each field or close Options.

Feed location

Open the list, then scroll (wheel or trackpad) or use arrow keys and Enter to pick a state.

Feed location saves when you pick a state. Save all settings flushes any field still being edited.

Reset extension

Clears saved settings, sets profile to Production, and revokes granted API host permissions. Side panel draft text is not cleared.
